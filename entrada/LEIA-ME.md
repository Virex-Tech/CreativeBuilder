# entrada/ — coloque aqui vídeos e imagens para usar nos criativos

Arraste para esta pasta (no VS Code ou no Explorador de Arquivos) qualquer material bruto:
gravações de tela do app, vídeos filmados, UGC, fotos, prints. Organize por app se quiser
(`entrada/ozempro/`, `entrada/tapfit/`).

Depois peça ao Claude Code, por exemplo:

> usa o vídeo entrada/ozempro/depoimento-uso-app.mp4 na cena 2, cortando de 0:12 a 0:18

O Claude copia **só o trecho usado** para `render/public/` (que vai para o GitHub). O que fica
aqui **não vai para o GitHub** — é pesado e é material bruto.
